# Общая библиотека ITP: план подключения

Известный базовый проект: `itpmining/vue_basic_components`.

При создании `Distrib-front` GitHub-подключение не смогло открыть этот репозиторий (404/недостаточно прав), поэтому точные экспорты и токены **не были проверены**. Чтобы не придумывать API и не ломать работу существующих продуктов, frontend включает временные UI-примитивы:

- `src/components/ui/AppIcon.vue`
- `StatusBadge.vue`, `MetricCard.vue`, `PageTitle.vue`
- `UiTable.vue`, `SectionCard.vue`, `ModalShell.vue`
- `OrderForm.vue`, `EmptyState.vue`, `ToastHost.vue`

## Порядок миграции (когда появится доступ)

1. Получить точный `package.json` и публичные экспорты библиотеки, её storybook и темы.
2. Создать `src/ui/library-adapter`, импортирующий **только существующие** компоненты и токены библиотеки.
3. Сопоставить Table, Button, Input, Select, Drawer/Modal, Breadcrumbs, Sidebar, Header, Cards.
4. Заменить временные имплементации на адаптеры с сохранением свойств и поведения экранов.
5. Синхронизировать шрифты, цвета, высоты контролов и состояния фокуса.
6. Протестировать desktop/mobile, доступность, состояние пусто/ошибка/загрузка, роль и печать.
7. Убрать временные UI-стили, которые были заменены библиотечными токенами.

**Не добавлять дубли уже существующих компонентов в библиотеку.** Исправления визуальных элементов должны в итоге попадать в общую библиотеку, а проект должен просто обновлять её версию. Отдельная работа по библиотеке не входит в текущий коммит.

Это не 1:1 унификация, пока библиотека не доступна.
